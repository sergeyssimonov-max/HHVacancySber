## Карантин и восстановление

Карантин: `output/.quarantine/2026-09-25/files/`.
Журнал: `output/.quarantine/2026-09-25/manifest.json`.
Он содержит исходные и новые пути, размеры, SHA-256, причины переноса и исходные
SHA-256 всех tracked-файлов. Записан до переноса, затем отмечено завершение.
Срок автоматического удаления **не назначен**. Фаза окончательного удаления
**не выполнялась**: содержимое остаётся до отдельного решения владельца.
Карантин локальный, уже покрывается существующим правилом `output/` в `.gitignore`;
в Git не хранится. Не запускать очистку ignored-файлов (`git clean -X/-x`),
пока владелец не решит судьбу карантина.

Для восстановления запустить из корня репозитория; сначала проверяется весь набор,
существующие файлы не перезаписываются:

```python
from pathlib import Path
import hashlib
import json

manifest = Path("output/.quarantine/2026-09-25/manifest.json")
data = json.loads(manifest.read_text())
for entry in data["entries"]:
    source, destination = Path(entry["quarantine"]), Path(entry["original"])
    assert source.is_file() and not source.is_symlink(), source
    assert not destination.exists() and not destination.is_symlink(), destination
    assert hashlib.sha256(source.read_bytes()).hexdigest() == entry["sha256"], source
for entry in data["entries"]:
    source, destination = Path(entry["quarantine"]), Path(entry["original"])
    destination.parent.mkdir(parents=True, exist_ok=True)
    # Exclusive creation prevents overwriting a file appearing after the check.
    with destination.open("xb") as restored:
        restored.write(source.read_bytes())
    assert hashlib.sha256(destination.read_bytes()).hexdigest() == entry["sha256"]
# Копии в карантине намеренно остаются до решения владельца.
```
