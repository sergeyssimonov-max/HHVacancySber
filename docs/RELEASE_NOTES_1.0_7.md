# СберВакансии 1.0 (7)

- IT-вакансии выделяются сине-зелёным текстом, вакансии информационной безопасности — тёплым оттенком и подписью «ИБ». Цвета работают в обеих темах, включая раскрытые описания.
- Начальный поисковый периметр расширен до 45 работодателей. Неизменённые старые списки обновляются автоматически; пользовательские настройки сохраняются.
- Скрытие раскрытой карточки отменяет загрузку описания; поздний ответ не возвращает скрытую карточку.
- При HTTP 429 разрешены максимум два повтора с Retry-After и ограниченными паузами. HTTP 403 не повторяется. Живые тесты остаются выключенными по умолчанию и сохраняют собственные бюджеты.
- Повторный автоматический экспорт избранного создаёт новый PDF с суффиксом, сохраняя существующий файл. Учтён байтовый размер Unicode-имён macOS.
- Сохранены исправления отмены, архивных статусов, статистического PDF и транзакционного восстановления файлов.

Проверки исходного кода перед выпуском: 116 модульных тестов (6 штатных пропусков), 13 UI, отдельный пятиитерационный XCTMetric, 72 Python; Debug и Release build/analyze успешны. Выпуск дополнительно проверяется штатным release.sh и CI отправленного коммита.

Ограничения: PDF не гарантирует побайтовую повторяемость между запусками; фиксированные метаданные не реализованы. Выбор личного и статистического PDF через системную панель сохраняет подтверждение замены. Кеш сессии не получил нового TTL/лимита. Измеренного ускорения или снижения памяти этот выпуск не заявляет.

macOS 13+, Apple silicon (arm64). Подпись ad-hoc, без Developer ID и нотариализации.

Очистка перед выпуском: удалён только пустой каталог tmp. Исходники, миграционные снимки, отчёты и проверочные материалы сохранены.

Сборка 7 завершает выпуск после проверки кандидата 6: исправлено строгое @Sendable-замыкание времени и переносимость проверки извлечения PDF-текста между macOS 13 и 15. Проверка требует все символы контрольных маркеров ровно один раз и проверяет точный исходный текст; различия переносов PDFKit не считаются потерей содержимого.
