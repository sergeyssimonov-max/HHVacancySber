# СберВакансии 1.1 (9)

- При временной ошибке одного работодателя сохраняются полученные вакансии и показывается предупреждение о неполной выгрузке. Короткая выдача перечитывается один раз, неполный результат не выдаётся из кэша как полный.
- Добавлены ограниченные повторы при временных сетевых ошибках и ответах HH 500/502/503/504.
- Загрузку выборки и экспорт избранного можно отменить той же кнопкой. При отмене поиска сохраняются предыдущие результаты.
- Описания избранных вакансий загружаются и сохраняются даже вне текущего поиска. Недоступные по HTTP 404 вакансии при проверке помечаются архивными.
- Улучшены подготовка и пагинация PDF, сохранена единая обычная гарнитура названий и дат в статистическом отчёте. Повторный экспорт избранного создаёт файлы с новым суффиксом, сохраняя существующие.
- Снижено накопление временных объектов при преобразовании HTML в текст; добавлены проверки параллельного преобразования.
- Выпуск собирается из снимка commit. DMG и контрольная сумма публикуются без перезаписи существующих файлов.

macOS 13 или новее, Apple silicon (arm64). Установка: открыть DMG и перенести
«СберВакансии.app» в «Программы». Пользовательские настройки и избранное сохраняются.

Подпись ad hoc, без Developer ID и нотариализации Apple. При первом запуске на другом
Mac может потребоваться разрешение в «Системные настройки → Конфиденциальность и безопасность».

Рядом с DMG опубликован файл SHA-256. В README внутри образа указан исходный commit.
