# Надёжность и память: измеренный результат 25.09.2026

Принята одна production-правка: локальный `autoreleasepool` вокруг существующего
преобразования `String.readableHTMLText`. Временные Foundation-объекты освобождаются
после каждого преобразования, а не накапливаются до освобождения внешнего пула.
Возвращаемая строка остаётся во владении вызывающего кода. Порядок замен, регулярные
выражения, содержимое результата, работа с файлами и обработка ошибок не менялись.

## До / после

Пять отдельных процессов для каждой версии, один и тот же harness, `swiftc -O`,
Xcode 15.2 / Swift 5.9.2, macOS 13.7.8 arm64, одинаковые unrestricted-разрешения.
Команда: `benchmark enrichment-favorites 500`. Это два последовательных экспорта
500 избранных вакансий через exporter-spy, без рендеринга PDF и без живой сети.
Время включает загрузку локальной фикстуры, переключение режима и два экспорта;
peak RSS — максимальный RSS всего процесса, включая создание входной фикстуры.
Ни сборки, ни тесты параллельно с timed-запусками не выполнялись.
Сначала измерен baseline, затем внесена одна правка и измерен кандидат.
Хеш harness одинаков в обеих сборках. Каждый процесс завершился с кодом 0.

больше разброса. Изменения CPU и wall менее 1%, ускорение не заявляется.
Правка принята за снижение памяти при сохранении семантики; уменьшение размера
бинарника не заявляется. Порог оценки ресурса — 5%; рост CPU/wall выше 5% либо
любое обнаруженное ухудшение корректности означали бы откат кандидата.

## Проверки надёжности

- На каждом timed-запуске проверены порядок и ID экспортируемых вакансий, два
  вызова экспорта и ровно N detail-запросов (повторный экспорт использует кэш).
- Сравнены старое и новое преобразования на 1331 комбинации из 11 фрагментов:
  Unicode, HTML-сущности, скрипты/стили, списки, переносы, пробелы и незакрытые теги.
  Результаты совпали на всех входах. Программа сравнения и обе версии бинарника
  сохранены в `/tmp/sber-perf-20260925/`; это временные локальные артефакты.
- Добавлен постоянный XCTest: 100 параллельных групп преобразований, сравнение
  возвращённых строк после освобождения всех локальных пулов.
- Итоговый XCTest: 131 всего, 125 прошли, 6 штатных opt-in пропусков, 0 ошибок.
  В набор входят проверки отмены, PDF, сохранения избранного и устойчивости снимка
  экспорта при изменении избранного во время асинхронной подготовки.
- Строгая подписанная Release-сборка успешна: `SWIFT_STRICT_CONCURRENCY=complete`,
  Swift/GCC warnings-as-errors. Проверка подписи и entitlements успешна.
- UI-тесты повторно не выполнялись: layout и UI-код не менялись.

## Воспроизведение

Для before взять production-исходники commit `04b3c15`, для after — текущую правку.
В **обеих** копиях использовать текущие `scripts/benchmarks/RuntimeBenchmarks.swift`
и `build.sh`, сверив SHA-256 harness с JSON. Компилировать отдельные бинарники одной
версией Xcode, затем последовательно по пять раз вызвать:

```sh
/path/to/before enrichment-favorites 500
/path/to/after enrichment-favorites 500
```

Сравнивать медианы и диапазоны пяти запусков, точные request/export counts,
все проверки семантики и результат XCTest. Не запускать сборки/тесты параллельно
с измерениями. Не сравнивать sandbox с unrestricted. Если выигрыш исчезнет
или проявится регрессия корректности, убрать только оболочку `autoreleasepool`.

## Отклонено / отложено

- Устранение повторного поиска ID при подготовке избранного: не включено;
  отдельной серии до/после нет. Эффекты нескольких изменений не смешивались.
- Изменения транзакций, отката PDF, сохранения пользовательских данных, retry,
  порядка публикации и отмены: не выполнялись ради выигрыша ресурсов.
- Агрессивные compiler flags, снижение валидации PDF, урезание Unicode/HTML:
  не рассматривались как допустимый обмен надёжности на скорость или размер.
- Пробный baseline на 5000 вакансиях: 99,06 с wall, 96,82 с CPU, 2,35 ГиБ RSS.
  Это один пробный запуск; after на этом размере не измерялся. Он не является
  доказательством выигрыша и не используется для принятия правки.
- Метрики относятся к локальной синтетической подготовке избранного. Они не
  доказывают аналогичный процент снижения памяти GUI, PDF-рендера или живого HH.
  Crash/disk-full испытания не проводились, код файловой записи не менялся.

Предыдущий отчёт гигиены и карантин сохранены. Коммит в этом проходе не создавался.
